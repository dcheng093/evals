## Description
The goal of this project is to complete Libft in its entirety. All files and functions have been created in accordance with the requirements of the subject pdf. It contains all the functions required by all 3 parts of the subject.

## Instructions
Using make will allow you to compile all the functions into the libft.a library. All the resulting object files created will stay in the root directory and is intended. The main branch will contain only the required files, with all the corresponding mains being in the testing branch. You may switch branches by using "git checkout [branchname], branchname being master or testbranch."
