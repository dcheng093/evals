# libft.a

## Description
Create your own library: a collection of functions that will be a useful tool for your curriculum.

This libraries contains several functions which are some implementation of libc functions like strlen or calloc, additional functions like ft_substr or ft_split and linked list functions.

## Instructions
Create the library using make
```
make
```
the libft.a will be created in the root directory of this project.

## Resources

* ft_substr is created according to this [c++ substr implementation](https://cplusplus.com/reference/string/string/substr/).
* all libc functions are created according to man [(website version)](https://linux.die.net/man/).
